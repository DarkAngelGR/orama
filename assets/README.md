# Orama branding assets

The Orama mark, "Fast Forward": two rounded play arrows, white then violet,
on an ink tile. The wordmark is "Or" in white (ink on light backgrounds)
plus "ama" in violet, set in Outfit 600.

Every image here and in `app/` is generated by one script, so the set always
matches:

```sh
python3 -I scripts/make-logo.py
```

## Start here

- `brand/logo-mark-1024.png`: the mark on its rounded tile, transparent corners.
- `brand/lockup-horizontal-light-1920x640.png` / `-dark-`: mark plus wordmark, for dark / light backgrounds.
- `brand/wordmark-light-1600x400.png` / `-dark-`: the wordmark alone.
- `icons/app-icon-*.png`: square RGB icons, 117 to 1024 px (full-bleed; launchers apply their own corner mask).
- `splash/`: 16:9 splash screens and wide banners.
- `tizen/`: Samsung/Tizen-specific deliverables (below).

In the app: `app/icon.png` (512 px launcher icon), `app/img/logo-mark.png`
(home header), `app/img/logo-560.png` (sign-in screen), `app/img/wordmark.png`
and `app/img/splash.png`.

## Samsung TV requirements

As checked by the original project against Samsung Developer documentation on October 10, 2026:

| Purpose | Samsung requirement | Included file |
| --- | --- | --- |
| Tizen Studio testing icon | 117×117 PNG | `tizen/icon-dev-117x117.png` |
| Seller Office logo layer | 1920×1080, 32-bit PNG (RGBA), under 300 KB | `tizen/seller-logo-layer-1920x1080.png` |
| Seller Office background | 1920×1080, 24-bit PNG (RGB) or JPG, under 300 KB | `tizen/seller-background-1920x1080.jpg` |
| Seller Office alternate icon | 512×423, 24-bit PNG (RGB), under 300 KB | `tizen/seller-icon-512x423.png` |

`tizen/seller-combined-preview-1920x1080.png` is a preview only: the logo
layer over the background.

The app itself ships a 512×512 `icon.png` so the launcher scales it down
rather than up on 4K TVs; if a TV shows it badly, copy
`tizen/icon-dev-117x117.png` over `app/icon.png`.

Official references:

- https://developer.samsung.com/smarttv/design/app-icons-and-screenshots.html
- https://developer.samsung.com/smarttv/design/smart-tv-application-design-qa.html
- https://developer.samsung.com/smarttv/develop/guides/fundamentals/managing-screen-resolution.html

## Colors

- Background (ink): `#0B0B12`
- Tile / raised: `#171724`
- Violet accent: `#8B7CFF`
- Text (soft white): `#F4F3FF`
- Ink text on light backgrounds: `#11111C`

Use the light wordmark on dark backgrounds and the dark wordmark on light
backgrounds. Give the mark breathing room of at least a quarter of its width.
